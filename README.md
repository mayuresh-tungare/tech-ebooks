# Tech eBook Library 📚

A curated collection of technical books, guides, and manuals. This repository is organized to support continuous learning across software engineering, AI, and IT operations.

## 📂 Repository Structure

The library is categorized as follows for easy navigation:

| Category | Description |
| --- | --- |
| **Artificial Intelligence** | AI Fundamentals, Neural Networks, and LLMs. |
| **Machine Learning** | Supervised/Unsupervised learning and Model deployment. |
| **Data Science & Viz** | Data analysis, Statistics, and Visualization techniques. |
| **Advanced Python** | Deep dives into Pythonic code and optimization. |
| **SQL** | Relational database management and complex querying. |
| **Algorithms** | Data structures and competitive programming logic. |
| **APIs** | REST, GraphQL, and Integration patterns. |
| **Cloud & Infra** | **Azure**, **IT Infrastructure**, and **Hardware** guides. |
| **DevOps & Ops** | **Rundeck**, **Monitoring**, and **Observability**. |
| **Enterprise Tools** | **ServiceNow**, **Splunk**, **CMDB**, and **MCP**. |
| **Management** | Engineering leadership and project management. |

---

## 🚀 Usage

1. **Search:** Use `GitHub's File Finder` (press `t` on your keyboard) to search for specific book titles.
2. **Download:** Click on the desired PDF and select the **"Download"** button.
3. **Clone:** To keep a local copy of the entire library:
`git clone https://github.com/your-username/your-repo-name.git`

---

## 🛠 Contribution Guide

Found a great resource?

1. Navigate to the relevant folder.
2. Ensure the filename follows the format: `Title_Author_Year.pdf`.
3. Upload via a Pull Request or the GitHub Web UI.
